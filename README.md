## Key Highlights

- **Dual-Discipline Positioning**: Balances IT infrastructure skills (Active Directory, Windows/Linux Server, Networking, Troubleshooting) with modern Web Development (React, Next.js, Node.js, REST APIs).
- **Aesthetic**: Inspired by Apple, Vercel, Linear, and GitHub. Clean typography, generous whitespace, subtle border accents, and refined micro-interactions.
- **Command Palette (`Cmd+K` / `Ctrl+K`)**: Keyboard-driven navigation across sections, external profiles, theme toggles, and resume actions.
- **Interactive Metrics**: Real-time counter animations for tickets resolved, projects completed, and certifications earned.
- **GitHub Live Stats Integration**: Built-in GitHub client that displays live stats and repositories with intelligent build-time caching and fallback.
- **Interactive Contact Form**: Integrated with Formspree with validation and success states.
- **Responsive & Accessible**: Fully WCAG 2.1 AA compliant with skip-to-content links, responsive mobile drawer menu, and dark/light modes.

## Getting Started

### Prerequisites

- Node.js 18.18+ or 20+
- npm 9+

### Installation

```bash
# Clone the repository
git clone https://github.com/unknownplanet40/rj-portfolio.git

# Navigate to project directory
cd rj-portfolio

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
# Export static production build to ./out
npm run build
```
